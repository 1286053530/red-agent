## 今日完成

### Agent 开发闭环

- Python 项目支持 pytest/unittest、解释器选择、语法检查与受控脚本执行；空测试及全跳过不能满足任务完成门槛。
- 修改展示逐文件差异，支持逐项接受、拒绝和恢复；应用、恢复前校验当前内容，保护用户已有修改。
- 保存目标、验收、计划、关键证据和待办；断点续作重新核对文件证据，将中断命令标为结果未知。
- 界面和后端统一读取与执行权限范围，明确项目目录、受控命令、网络及敏感路径边界；进程尚未做操作系统级隔离。
- 内置 Skill v1.1.0 根据任务加载审查、分析、修复、功能开发或重构指引，语言参考按需读取。

### 输入与模型连接

- 输入框随内容增高、收缩，达到高度上限后内部滚动。
- 支持 Ctrl+V 粘贴图片、拖入、预览和移除；图片草稿在首次选择项目及发送失败后保留，模型支持 Responses 图文与工具调用。
- 移除无响应的图片按钮和文件选择入口。
- 修复未选项目时无法输入草稿的问题；发送仍要求项目和模型，归档会话及运行中保留输入限制。
- 网络传输错误与超时最多尝试 5 次（首次请求加 4 次重试），等待 1/2/3/4 秒；停止任务会取消请求及等待，明确的 HTTP 错误直接报告。

### 页面浏览

- 小红书官网默认缩放 80%，可逐次缩小至 50% 并重置；导航后保持缩放。
- Agent 支持右侧页面小窗，与大窗复用网页状态；右栏支持拖动调宽、宽度记忆、键盘微调和复位。
- 修复窄栏文字重叠，将缩小及放大浏览改为带可访问名称的图标。
- 最终交互为点击对话空白或消息收起页面浏览；点击输入框、编辑内容保持页面展开，重新展开复用原页面。
- 2.1.28 移除网页标题、“关闭官网”按钮及说明文字，保留缩放、重置与放大浏览；按 Escape 关闭页面。
