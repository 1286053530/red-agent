# 权限与执行范围

此说明适用于当前源码与本地构建的安装包。权限菜单的范围由后端 `accessPolicy` 提供；任务轨迹展示该任务保存的实际权限、项目目录和模型地址。应用内项目 SSH 配置、远程命令与上传已于 2.1.51 移除。公网下载仍为 2.1.19；2.1.51 尚未上传。

| 模式 | 文件工具 | 项目检查 |
| --- | --- | --- |
| 只读分析 | 可列举、搜索和阅读允许范围内的源码，禁止生成和应用修改 | 禁止运行，即使请求传入自动执行标志也会关闭有效权限 |
| 逐项审核 | 源码修改逐项接受或拒绝 | 每条命令需批准后运行 |
| 自动执行 | 自动应用修改并保留恢复记录 | 自动运行受支持的检查 |
| 自定义 | 分别选择源码修改是否自动应用 | 分别选择检查是否自动执行 |

输入框权限只用于新任务。恢复、回答问题或审批不会从输入框重新读取授权。只读任务不能通过审批入口执行修改或命令；审批记录必须属于当前任务。恢复历史变更是用户显式操作，仍需当前会话处于可修改状态，并检查当前文件内容，避免覆盖后续修改。

## 目录与敏感配置

文件工具只访问导入项目内的 UTF-8 源码，拒绝绝对路径、路径越界、符号链接及目录联接。项目根目录固定在任务中；变更后需新建任务。依赖、构建与缓存仍按内置排除表过滤，目前不解析 `.gitignore`。

文件工具统一排除 `.env`/`.env.*`、`.ssh`、`.aws`、`.azure`、`.kube`、`.docker`、`.npmrc`、`.netrc`、`.pypirc`、`.gitconfig`、`.git-credentials`、常用私钥及凭据名称。不能导入这些敏感配置目录，不能通过导入父目录读取工作台数据目录中的会话、加密密钥或模型配置。过滤按路径名称进行，不能识别普通源码中混入的凭据。

模型密钥由后端加密保存，公开 API 和任务访问范围不返回原密钥。项目检查进程仅继承基础环境变量，不继承 `OPENAI_API_KEY`、`NPM_TOKEN`、`NODE_OPTIONS`、`PYTHONPATH` 等后端环境变量。

## 命令与检查进程

允许 `node --test/--check`、`npm test`、`npm run test/build/lint/typecheck/check`，以及受控 Python 的 pytest、unittest discover、py_compile 和相对路径项目脚本。Python 参数范围见 [Python 指引](../backend/skills/software-development/references/python.md)。直接工具不提供任意 shell、安装、发布操作。

审批展示命令、目的和项目脚本；npm 还展示对应的 `pre`、主脚本和 `post` 生命周期脚本。申请、批准和启动前校验命令、相对路径及源码版本；源码变化需重新申请。项目 Python 环境变化同样会取消执行。超时、停止与日志继续由受控进程管理器处理。

**检查进程以本机账号运行，工作目录为项目根目录。它没有操作系统级文件或网络隔离。** 项目脚本及其依赖可以访问项目外目录、本机配置、凭据文件和网络，也可以启动 shell、安装程序或其他子进程。审批允许本次运行这些项目代码；自动执行只减少审批，不改变这一范围。界面不提供虚假的“禁止联网”或“进程仅能访问项目目录”开关。

## 联网与模型数据发送

后端将任务描述、用户添加的图片、读到的源码、命令输出及历史发送到配置的模型 Base URL。任务固定其接口地址、协议和模型；修改后恢复旧任务会被拒绝，需新建任务确认新的数据发送范围。原密钥可以由用户更新，任务日志不保存原密钥。

图片仅接受消息中显式添加的 PNG/JPEG/WebP Base64 数据，不接受远程图片 URL 或项目文件路径。后端检查数量、大小、Base64 和格式签名；每条消息最多 4 张、单张 5 MB、合计 12 MB。原图存入本地工作台数据目录，会话状态和日志保存引用；图片读取接口验证其属于对应会话，并复用本机访问与桌面令牌校验。任务请求才临时展开 Base64，三种协议分别转换图文消息；Responses 使用 `store: false`，在本地保留工具调用及不透明推理项以继续任务。

Agent 没有任意 URL 抓取或浏览器自动化工具。检查进程联网未隔离；手动小红书网页的网络访问属于独立浏览视图，不由任务执行权限控制。

## 验证

`tests/python/test_access.py` 覆盖伪造授权、只读审批绕过、跨任务审批、启动前范围复核、敏感配置与内部数据目录保护、模型目标固定、npm 生命周期展示和环境变量过滤。`tests/python/test_composer.py` 验证界面模式对应真实任务权限、展示后端范围，并确认切换下一任务权限不修改当前任务。
