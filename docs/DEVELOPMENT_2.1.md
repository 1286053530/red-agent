# 2.1 系列开发与交付记录

记录日期：2026-10-25（北京时间）。当前桌面版本：2.1.19。

## 产品定位与界面

系统以软件开发 Agent 为主，小红书只提供手动浏览入口。最左侧按房子（Agent）、图书（小红书）排列；Agent 页采用项目会话侧栏、中间对话、右侧项目文件/任务轨迹的布局。项目和会话可折叠，会话可归档、恢复，运行中显示转圈标志；侧栏可滚动、拖动调宽并保存宽度。

移除了多余顶部介绍、旧内容功能菜单及独立模型配置行。当前模型和本次任务权限收进输入框内的弹出菜单；Skill 配置在界面隐藏，但新任务仍默认加载内置软件开发 Skill。Agent 标题显示当前任务名，发送按钮仅在有输入时出现。

Python 后端管理项目、模型、权限、任务循环与记录；Electron 管理桌面窗口、文件夹选择和隔离的手动官网视图。单个任务采用单 Agent 工具反馈循环，辅以计划与 Skill 指引，未实现多 Agent 编排。

## 开发规范与小红书浏览

`backend/BASE.md` 每轮加载，规定定向调查、计划、实现/审查、实际验证和证据交付。Skill 资源按需加载，任务启动时保存快照。源码、文档与工具输出不授予权限。

小红书使用隔离的 WebContentsView。首次打开需要用户点击；切到 Agent 时只隐藏视图，返回后复用页面、滚动位置和网页内状态。关闭官网或退出软件时才销毁。工作台不检测账号、不提取二维码、不采集推荐或私信；页面自身仍有正常网络请求。

## 2.1.18：大项目读取

- UTF-8 源码流式分段读取，单页最多 12,000 字符；支持中文、超长单行、行号定位和字符偏移。
- 稀疏索引缓存支持连续分页，文件变化后失效。前端以“上一段/下一段”控制预览节点数量。
- 目录默认只加载当前层，每页 200 项；用户点击展开，模型可限定路径或递归分页。
- 搜索可限定目录/文件，达到返回或扫描预算后给出续查游标；依赖、构建产物、缓存、敏感文件和符号链接/联接被排除。
- 取消旧版 1,200 文件、6,000 条目、10 层和快照单文件 20 MB 硬限制，快照哈希按块计算。
- 审查允许读取相关片段后明确覆盖范围；完整替换仍限 160 KB，且须先读全当前版本。

验证包含 24 MB 超长单行的内存使用、UTF-8/CRLF 分页完整性、深层目录、超过 1,200 文件、搜索边界和前端按需加载。

## 2.1.19：任务可靠结束

- `finish_task` 必须通过原有验收门槛，才标为完成。只读审查不伪称已运行行为测试。
- `request_user` 提供具体问题和原因后暂停模型；用户回答继续同一任务。
- `fail_task`、模型接口异常、预算耗尽和持续无进展明确标为失败，保留证据，可显式重试。
- 工具失败返回分类和纠正建议，近期失败随上下文传给模型。
- 成功读取同一范围最多两次；外部文件变化或源码修订后允许重读。相同失败操作两次后拦截原样重试。
- 连续五次错误、三次重复拦截或十轮没有新证据会停止本次尝试；正常分页推进不被误判为空转。
- 同一源码与命令最多两次失败执行；批量调用在需要审核或等待运行结果时暂停，补齐工具消息，避免越过审核或遗留错误的消息结构。
- 人工重试保留前次结果并开启新尝试；审核后的自动继续保留防循环记录。

## 当前限制

行为检查仍只支持受控 Node/npm 命令，尚不支持直接运行 Python/pytest。命令许可不是操作系统沙箱。内置规范、状态机与防循环机制不能保证任意模型必然完成任务；仍需用实际项目和模型评估质量。安装包尚未签名；下载页提供 SHA-256 校验值。
