# 小红书手动访问修复记录

> 历史版本 2.0.1。2.0.2 按用户选择增加手动内嵌官网，自动化采集保持停用；当前说明见 [手动内嵌官网](MANUAL_EMBEDDED_ACCESS.md)。

日期：2026-10-24（北京时间）。版本：2.0.1。

用户提供了账号异常提醒，平台指出近期浏览行为与真人习惯不一致。代码复查确认旧版存在状态轮询、启动恢复官网会话、页面脚本检查、二维码提取、程序点击和滚动、推荐与消息采集。这些行为可能与告警有关；缺少平台判定和完整访问日志，不能断言某个动作是唯一原因。

## 当前行为

- 启动、切换页面、窗口恢复和空闲等待不会恢复或访问小红书官网会话。
- 移除内嵌 WebContentsView、页面脚本执行、二维码读取、自动点击、滚动和内容提取。Python 后端不再导入或启动 Playwright，冻结安装包排除其驱动。
- 小红书入口为用户主动点击的固定官网首页，桌面通过系统默认浏览器打开；网页通过普通外链打开。没有伪装指纹、模拟真人节奏、自动重试或绕过验证逻辑。
- 旧 connect、login/refresh、recommendations、messages 接口在 HTTP 路由层直接返回 410，拒绝旧页面或第三方旧客户端继续触发采集；原生通信白名单仅保留项目目录选择与本软件旧登录数据清理。
- 不再检测或显示账号是否登录。推荐与消息页面明确展示自动读取已停用，用户在官方页面中自行操作。
- 旧会话保留在原位置，不自动加载或删除。清理需要用户点击并确认，只删除本软件旧会话数据，不访问官网退出、不清理系统浏览器。
- 开发 Agent 的模型接入、项目管理、修改审核、检查执行与恢复机制保持原有功能。

## 升级与限制

退出 2.0.0 及更早版本，再使用 2.0.1 安装包或免安装版。修改源码和下载新版不会自动停止已经运行的旧客户端。已有平台告警需要按官方提示处理；本修复不承诺解除告警或保证账号绝不再触发限制。

测试和构建只使用隔离数据及本地样本，不再用真实账号或官网验证采集能力。
