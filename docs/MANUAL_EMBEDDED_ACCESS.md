# 手动内嵌官网访问

版本：2.0.2。日期：2026-10-24（北京时间）。用户选择在工作台中内嵌访问官网。

桌面版使用 Electron WebContentsView，在用户点击后加载官方首页。它是一块供用户操作的浏览器页面，不是账号授权或消息 API 接入：用户自行登录、打开消息和发送回复，工作台不读取官网 DOM、Cookie、二维码、账号状态、消息列表或未读数。

## 访问与生命周期

- 启动、切换页面和恢复窗口不加载官网。用户点击时才创建官网页面。
- 新页面使用独立持久会话 `persist:xiaozhu-manual-v1`，不导入此前自动化会话的 Cookie。
- 点击「返回工作台并关闭官网」、按 Escape、最小化或隐藏窗口，会销毁官网 WebContents 并关闭会话连接；会话网络拦截器在没有可见官网页面时拒绝新请求，包含后台 worker 的请求。
- 官网自身在用户打开页面期间会运行脚本并联网；本应用不模拟用户行为，也不控制或伪装官网的风控。
- 官网主页面仅允许小红书指定官方域名，弹窗和站外跳转不自动放行；如官网需要额外窗口或不支持此环境，可主动选择系统浏览器。不会忽略证书错误或改写浏览器指纹。
- 官网无 Node 集成、无工作台 preload，启用 sandbox 和 contextIsolation；不向官网开放本地项目和模型工具，拒绝下载和额外设备权限。
- 用户明确确认后，可清理本软件的手动内嵌及旧版会话；不会清理系统浏览器。

Python 后端的旧登录、二维码刷新、推荐与消息采集接口保持 HTTP 410。没有恢复自动连接、采集或消息发送接口。网页版继续使用普通官网外链。

## 实际能力与限制

用户可以在一个桌面窗口中手动访问官网。能否登录和访问消息由官网页面及账号状态决定；本次不使用真实账号验证，不承诺不会再告警。不能在工作台独立展示实时消息列表、完整通知或未读数；这些仍需要对应官方 API 权限。

测试使用隔离的 HTTPS 页面样本：已有 Cookie 不触发自动访问，主动打开后页面脚本可以正常运行，返回后页面和定时器销毁、会话网络阻断，重启后仍需主动打开；另验证官网没有 Node 或本地桥接权限。真实平台账号已告警时，应优先按官方指引处理。
