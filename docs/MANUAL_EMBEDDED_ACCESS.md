# 手动内嵌官网访问

适用版本：2.1.25；本页保留浏览状态的功能记录始于 2.1.14（2026-10-25）。文档更新：2026-10-26（北京时间）。官网可在账户页大窗或 Agent 右侧“页面浏览”小窗显示，默认缩放为 80%；切换模块保留现有网页。缩小网页与放大浏览使用带辅助名称和提示的图标按钮；窄栏标题以单行省略显示。

桌面版使用 Electron WebContentsView，在用户点击后加载官方首页。页面尺寸跟随当前大窗或小窗的显示区域，保留工作台布局，不创建新窗口。小窗入口为 Agent 右侧“页面浏览”→“在工作台内打开官网”；点击“放大浏览”进入账户页大窗。工作台只读取自身占位区域的尺寸，不读取官网内容。它是一块供用户操作的浏览器页面，不是账号授权或消息 API 接入：用户自行登录、打开消息和发送回复，工作台不读取官网 DOM、Cookie、二维码、账号状态、消息列表或未读数。

## 访问与生命周期

- 启动和首次切换页面不加载官网，用户点击时才创建。打开后切到 Agent 的项目文件或任务轨迹标签只隐藏网页；选择“页面浏览”则在右侧复用同一 WebContents，不重新加载首页；保留页面 URL、浏览位置和页面内临时状态。
- 大小窗共用一个官网页面，默认 80% 缩放。“缩小”每次降低 10 个百分点，最低 50%；“重置”恢复 80%。页面导航和大小窗切换继续保持所选比例；同次应用运行内关闭重开也保留，重启软件恢复默认。
- 页面浏览标签打开时，点击任务对话空白、消息或输入框会收起右栏并隐藏网页，输入框仍可继续输入。点击“展开项目文件”恢复当前页面浏览标签和原网页，不重新加载首页；其他右栏标签不因对话点击而收起。
- Agent 右栏左边缘支持左右拖动调宽并记忆；双击或 Home 恢复默认，方向键微调。拖动期间暂时隐藏原生网页，松开按新尺寸恢复，保留现有页面。窄屏纵向布局不显示调宽条。收起 Agent 右栏、打开模型设置或图片预览时隐藏网页，返回后恢复；中间对话与任务执行继续。
- 新页面使用独立持久会话 `persist:xiaozhu-manual-v1`，不导入此前自动化会话的 Cookie。
- 最小化或隐藏窗口保留网页，恢复窗口时只有此前正在显示官网才重新显示；在 Agent 界面恢复窗口不会把官网覆盖上来。
- 点击「关闭官网」、在未打开设置、图片预览或输入框菜单时按 Escape、清理登录数据或退出软件才销毁 WebContents 并关闭会话连接。页面关闭后阻止后续请求，包括后台 worker；同一次软件运行期间保留网页，不承诺跨进程恢复页面状态。
- 保留的官网网页可像普通浏览器后台标签页一样运行自身脚本和连接；本应用不读取页面内容、不模拟用户行为，也不控制或伪装官网的风控。网站自身刷新、登录过期或导航仍由网站决定。
- 官网主页面仅允许小红书指定官方域名。官网中的新窗口链接复用当前内嵌页，不创建窗口；站外链接及跳转被阻止。桌面版不提供系统浏览器打开入口，不会忽略证书错误或改写浏览器指纹。
- 官网无 Node 集成、无工作台 preload，启用 sandbox 和 contextIsolation；不向官网开放本地项目和模型工具，拒绝下载和额外设备权限。
- 用户明确确认后，可清理本软件的手动内嵌及旧版会话；不会清理系统浏览器。

Python 后端的旧登录、二维码刷新、推荐与消息采集接口保持 HTTP 410。没有恢复自动连接、采集或消息发送接口。网页版继续使用普通官网外链。

## 实际能力与限制

用户可以在一个桌面窗口中手动访问官网。能否登录和访问消息由官网页面及账号状态决定；本次不使用真实账号验证，不承诺不会再告警。不能在工作台独立展示实时消息列表、完整通知或未读数；这些仍需要对应官方 API 权限。

测试使用隔离的 HTTPS 页面样本：已有 Cookie 不触发自动访问，切换时复用页面并保留 URL、实际滚动位置和临时状态；明确关闭后页面和定时器销毁、会话网络阻断，重启后仍需主动打开；另验证官网没有 Node 或本地桥接权限。
