# 筱竹书瑾 AI 软件开发工作台 | Python | FastAPI | Electron

筱竹书瑾 AI 软件开发工作台 | Python | FastAPI | Electron | JavaScript | AI 编程 | 代码审查 | 多模型接入

筱竹书瑾是一款面向本地项目的 AI 软件开发工作台，集项目管理、源码分析、代码修改、差异审核、测试验证与任务记录于一体。用户通过自然语言描述需求，Agent 结合项目源码制定计划、调用工具、执行检查，并根据结果继续修正，让开发过程有步骤、修改有审核、交付有依据。

【技术栈】

① 后端：Python、FastAPI、Uvicorn、HTTPX  
② 前端：原生 HTML、CSS、JavaScript  
③ 桌面：Electron、WebContentsView、Windows x64  
④ AI 接入：OpenAI Chat Completions、OpenAI Responses API、Anthropic Messages 协议  
⑤ 数据与凭据：本地 JSON 持久化、JSONL 任务轨迹、AES-256-GCM 密钥加密保存  
⑥ 验证与打包：pytest、unittest、Node.js Test Runner、PyInstaller、electron-builder

【使用方式】

面向开发者的本地桌面工作台，导入项目并配置支持工具调用的模型服务后即可使用。按任务选择只读分析、逐项审核或自动执行权限，适用于代码审查、问题分析、缺陷修复、功能开发与代码重构。任务内容和读取的源码会发送至用户配置的模型接口。

【项目与会话功能】

- 项目管理：导入本地项目，按项目组织开发任务与历史会话。
- 会话管理：新建、切换、归档与恢复会话，保留对话及执行记录。
- 工作台布局：项目侧栏、任务对话、项目文件、任务轨迹与页面浏览集中展示，侧栏宽度可拖动调整并记忆。
- 任务状态：区分执行中、已完成、执行失败与等待回答，支持停止任务、补充信息及失败重试。
- 历史续作：保存任务目标、计划、关键证据与执行结果，支持中断后的人工继续。

【AI 开发功能】

- 自然语言开发：围绕用户目标制定计划，结合工具结果推进分析、实现与验证。
- 源码分析：浏览项目目录、搜索代码、分页读取大文件，定位相关实现与调用关系。
- 代码审查：按相关代码范围分析问题，提供文件位置、证据与修改建议。
- 代码修改：根据任务提出文件变更，支持问题修复、功能开发与重构。
- 图文输入：支持粘贴或拖入图片，结合截图描述界面问题与需求；需使用支持视觉输入的模型。
- 开发指引：每轮加载基础开发规范，内置软件开发 Skill，按任务加载审查、分析、修复、开发或重构流程。
- 多模型配置：自定义接口地址、模型名与 API Key，支持连接测试和模型切换。

【审核与验证功能】

- 差异审核：逐文件展示修改原因、增删行数及行级差异，支持接受或拒绝变更。
- 修改保护：应用前检查文件基线，恢复前检查当前内容，遇到外部修改时阻止直接覆盖。
- 权限控制：按任务保存实际访问权限、项目目录与模型接口地址，按授权执行修改与检查。
- Node 项目检查：支持 Node 测试、语法检查，以及约定范围内的 npm 测试、构建、Lint 和类型检查脚本。
- Python 项目检查：支持 pytest、unittest、语法检查与项目脚本，优先使用项目虚拟环境。
- 验证交付：修改任务需通过当前源码的行为测试并完成最终差异复核，才能标记完成。
- 过程追踪：记录计划、工具调用、命令输出、修改与审核结果，支持导出任务日志。

【桌面辅助功能】

- 本地运行：桌面包内置应用后端所需的 Python 运行时，提供 Windows x64 安装版与免安装版。
- 手动页面浏览：内嵌小红书官网，支持大小窗切换、缩放与浏览状态保留，可在等待 Agent 任务时手动使用。
- 凭据保存：模型 API Key 在本地加密保存，接口不返回原始密钥。

【项目亮点】

① AI 开发闭环：需求理解 → 源码调查 → 计划制定 → 代码修改 → 检查纠错 → 差异复核 → 证据交付。  
② 修改过程可控：逐项差异审核、任务权限配置、文件基线校验与修改恢复，便于掌握每一次代码变更。  
③ 验证结果可追踪：记录真实命令与测试结果，将行为测试和最终复核纳入修改任务的完成条件。  
④ 多模型统一接入：支持三类模型接口协议，可按项目需要配置兼容的模型服务。  
⑤ 面向实际项目：支持大文件分页读取、目录按需展开与搜索续查，减少无关源码加载。  
⑥ 任务持续推进：结合上下文摘要、网络连接重试、失败纠正与防循环机制，支持任务恢复与问题追踪。

文案依据当前 2.1.28 版本的已实现能力整理。项目检查需要准备对应的项目解释器、工具和依赖；内嵌官网由用户手动操作。
