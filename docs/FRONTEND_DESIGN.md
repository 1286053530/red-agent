# Agent 工作台视觉约定

参考：https://github.com/anthropics/skills/tree/main/skills/frontend-design

方向：面向长时间编码与审查的紧凑工具界面。主要框架保持不变，移除开发页顶部导航、日期和介绍区，控制项合并到 Agent 标题栏。

## 基础变量

- 工作背景 `#f7f8fa`，内容纸面 `#ffffff`。
- 正文 `#253044`，次要文字 `#667085`，边界 `#e4e7ec`。
- 主操作与选中状态 `#315deb`；其余区域保持低饱和中性色。
- 中文使用系统微软雅黑，英文使用系统 Segoe UI，源码使用 Cascadia Code / Consolas；不远程加载字体。
- 正文 14px，辅助信息 12px，工具栏标题 14px；空间采用 4/8/12/16/24px 层级。

## 布局

```text
项目侧栏           Agent 标题、侧栏开关、设置       文件工具栏
项目与会话         对话内容                         文件树 / 源码
                   对话内容（独立滚动）             （独立滚动）
                   执行记录与待审核项
小红书休闲入口     模型 / 任务权限 / 输入区
```

审视：品牌不采用营销页大标题；可用空间优先给任务、对话和源码。原有项目、会话、文件、模型、Skill、执行与审核功能保留，三处收起/展开保持可达。视图折叠时保留恢复控件和键盘焦点。低高度、窄屏允许页面滚动以保证输入与审核可达。

项目信息和 Skill 配置、查看指引及说明区在主界面隐藏；新任务继续默认启用内置软件开发 Skill，基础规范照常加载。

右侧使用“项目文件 / 任务轨迹 / 页面浏览”标签。“页面浏览”提供手动打开小红书的小窗，官网默认缩放为 80%，工具栏只显示缩小、重置和放大浏览控件，不显示网页标题、关闭按钮或说明文字。缩小图标逐次降至 50%，重置恢复 80%，放大浏览图标切到账户页。右栏左侧提供独立拖拽条，左右调宽并记忆，支持双击和 Home 复位、方向键微调。拖动期间隐藏原生网页以保证拖拽事件不中断，松开后按新尺寸恢复。窄屏纵向布局隐藏调宽条。保留中间对话和输入区；大窗与小窗复用同一页面和滚动位置。切换其他标签、收起右栏或打开设置及图片预览时隐藏官网，返回后恢复。首次选择标签只显示打开入口，用户点击后才加载网页。

任务输入区随输入、换行和粘贴内容自动增高，删减或发送清空后自动收缩。最小高度 80px，最高为 320px 或视口高度的 35%（取较小值），超过上限仅文本区内部滚动，底部模型、权限和发送操作保持可见。窗口缩放、面板展开/折叠和返回工作台时按实际可用宽度重新计算换行高度，不需要手动拖动。

图片直接 Ctrl+V 粘贴到输入框或拖入，不显示单独的图片按钮或文件选择入口。发送前以缩略图显示文件名和移除按钮，允许纯图片发送；未选择项目时可暂存图片草稿，首次选项目后保留。文件数量、格式和大小由前后端共同校验。请求被拒绝时保留草稿，服务接受后清空。历史图片使用本机会话接口加载，不将 Base64 塞入轮询状态；点击后在应用内对话框放大，Escape 关闭，兼容桌面端禁止新窗口的限制。模型设置明确区分 Chat Completions、Responses 和 Anthropic，图片要求模型具备视觉能力。

界面反馈以实际状态为准，不用装饰性数字或无含义标签。禁用、错误、待审核等状态在视觉上明确区分。遵循减少动画偏好，保持可见的键盘焦点。用实际浏览器检查空状态、对话、源码、折叠、设置和窄屏。
