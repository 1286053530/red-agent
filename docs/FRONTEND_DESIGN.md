# Agent 工作台视觉约定

参考：https://github.com/anthropics/skills/tree/main/skills/frontend-design

方向：面向长时间编码与审查的紧凑工具界面。主要框架保持不变，移除开发页顶部导航、日期和介绍区，控制项合并到 Agent 标题栏。

## 基础变量

- 工作背景 `#f7f8fa`，内容纸面 `#ffffff`。
- 正文 `#253044`，次要文字 `#667085`，边界 `#e4e7ec`。
- 主操作与选中状态 `#315deb`；其余区域保持低饱和中性色。
- 中文使用系统微软雅黑，英文使用系统 Segoe UI，源码使用 Cascadia Code / Consolas；不远程加载字体。
- 正文 14px，辅助信息 12px，工具栏标题 14px；空间采用 4/8/12/16/24px 层级。

## 布局

```text
项目侧栏           Agent 标题、侧栏开关、设置       文件工具栏
项目与会话         对话内容                         文件树 / 源码
                   对话内容（独立滚动）             （独立滚动）
                   执行记录与待审核项
小红书休闲入口     模型 / 任务权限 / 输入区
```

审视：品牌不采用营销页大标题；可用空间优先给任务、对话和源码。原有项目、会话、文件、模型、Skill、执行与审核功能保留，三处收起/展开保持可达。视图折叠时保留恢复控件和键盘焦点。低高度、窄屏允许页面滚动以保证输入与审核可达。

项目信息和 Skill 配置、查看指引及说明区在主界面隐藏；新任务继续默认启用内置软件开发 Skill，基础规范照常加载。

界面反馈以实际状态为准，不用装饰性数字或无含义标签。禁用、错误、待审核等状态在视觉上明确区分。遵循减少动画偏好，保持可见的键盘焦点。用实际浏览器检查空状态、对话、源码、折叠、设置和窄屏。
