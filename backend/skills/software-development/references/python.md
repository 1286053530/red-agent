# Python

从 pyproject.toml、requirements 文件、项目入口和现有测试确认 Python 版本、框架、包结构与依赖约定。避免把导入成功等同于业务正确。修改异步服务时检查阻塞 I/O、任务取消、连接和文件关闭、异常映射及启动/关闭生命周期。

对于参数或接口改动，追踪路由、调用方、数据格式、持久化与旧数据兼容性。修复应覆盖出错条件及正常行为，不用宽泛 except 掩盖根因。测试需要隔离临时目录、外部请求和账号数据，避免测试污染用户实际数据。

本工作台目前的 run_command 仅支持 Node/npm 检查，尚不支持直接执行 python、pytest、pip 或任意 shell。可以读写 Python 源码、进行只读分析；如果项目已有经过用户授权、实际覆盖相关行为的受支持检查，可按原脚本运行。否则明确缺少 Python 执行验证能力及需要用户运行的具体检查，保留任务请求帮助。不要声称已经运行 pytest，不制造 Node 空测试，不改写 package.json 来绕过限制，不把未验证的 Python 修改标为已验证完成。
