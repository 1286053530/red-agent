# JavaScript / TypeScript / Node

从 package.json、锁文件、项目入口和相关测试确认模块格式、运行版本和现有检查脚本。保留 ESM/CJS、导入路径、异步 API 及错误传递约定；修改共享函数时检查调用方。TypeScript 项目使用项目已有配置与工具，不把 node --check 当作类型检查，也不直接用它解析 TypeScript。

定位异步问题时核对返回 Promise、取消信号、超时、资源清理和失败分支；不要通过吞掉异常让测试变绿。接口改动同时检查请求方对字段、状态码及空值的假设。UI 改动考虑加载、错误、空数据和重复操作，源码检查与真实浏览器验证应分别报告。

当前可申请 node --test、node --check，以及 npm 的 test/build/lint/typecheck/check 既有脚本。先读清 npm 脚本实际含义及依赖要求，不重写脚本以绕过命令范围。语法、构建和 lint 不能单独证明行为正确。内置 Node 测试需要真实成功用例；npm test 的退出码不能证明用户要求的业务一定覆盖。

只运行能够解释本次行为的检查，失败时记录命令与诊断，修正后重跑有关检查。测试执行会运行本机项目代码，审批范围仍由任务权限决定；Skill 不授权安装、发布、删除或任意 shell。
